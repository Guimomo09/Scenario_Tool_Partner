# Prompts Portables — Mode d'Emploi

## 🎯 C'est Quoi ?

Des prompts prêts à copier-coller dans **n'importe quelle IA** (ChatGPT, Claude.ai, Gemini, etc.) quand tu n'as pas accès à VS Code.

## 📁 Fichiers Disponibles

| Fichier | Usage |
|---------|-------|
| `PROMPT-CHATGPT.md` | Writing Partner — écriture & critique |
| `PROMPT-WORLDBUILDER.md` | World-Builder — création d'univers |

## 🔄 Workflow

### 1. Tu es ailleurs (pas sur VS Code)
- Ouvre ChatGPT/Claude depuis ton téléphone, navigateur, etc.
- Copie le prompt depuis le fichier correspondant
- Colle + ajoute ton contenu

### 2. Tu trouves quelque chose de bien
- Copie le résultat de l'IA
- Sauvegarde dans `Inbox/NOTES.md` (accessible via OneDrive)

### 3. Tu reviens sur VS Code
- `@Writing Partner inbox` → Il intègre tes notes

## ⚠️ Limites

Les prompts portables ne peuvent PAS :
- Accéder à tes fichiers automatiquement
- Garder la mémoire entre sessions
- Mettre à jour tes documents

**Solution** : Copie-colle manuellement et utilise l'Inbox.

## 💡 Astuce

Garde ce dossier `Portable/` sur OneDrive pour y accéder depuis ton téléphone ou n'importe où.
