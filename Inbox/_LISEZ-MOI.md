# 📥 Inbox — Mode d'Emploi

## C'est Quoi ?

L'Inbox est un dossier de "dépôt rapide" pour noter des idées depuis **n'importe où** :
- Bloc-notes Windows
- Word
- Mail (sauvegarde en .txt)
- Téléphone (via OneDrive)
- Navigateur (copier-coller)

## Comment Ça Marche

### 1. Note Rapide
Ouvre `NOTES.md` et écris ce que tu veux :
- Une idée de scène
- Un feedback sur ton scénario
- Une question
- Un dialogue qui t'est venu

### 2. Fichiers Déposés
Tu peux aussi déposer des fichiers entiers ici :
- Un `.txt` avec des notes
- Un `.md` avec du contenu
- Copie d'un mail avec des idées

### 3. Traitement
Quand tu reviens sur VS Code :
```
@Writing Partner inbox
```
→ Il lit tout, traite, et déplace dans le bon projet

## Format Recommandé

Pour que le Partner comprenne mieux, préfixe tes notes :

```markdown
[PROJET: Origine Martienne]
Idée : Et si le personnage X avait en fait...

[QUESTION]
Pourquoi le système de magie ne permettrait pas de...?

[DIALOGUE]
A: "Réplique cool que j'ai pensé"
B: "Réponse"

[FEEDBACK]
Le chapitre 3 me semble trop lent au début...

[TODO]
- Revoir la timeline de l'arc 2
- Ajouter une scène entre X et Y
```

## Accès Rapide

Une fois le dossier sur OneDrive, le chemin sera :
```
C:\Users\charl\OneDrive\Partner\Inbox\NOTES.md
```

Tu peux créer un raccourci sur ton Bureau pour y accéder en 1 clic.
